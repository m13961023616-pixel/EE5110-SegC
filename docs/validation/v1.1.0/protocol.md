# v1.1.0 独立性能验证方案

本轮开发调试使用 seed=43 的 36 场景及固定场景，调试数据不作为正式成功率。
冻结控制与规划参数后，用以下未参与调参的种子验证。

| 组 | 任务 | 种子 | 场景数 | 抽样 |
|---|---|---:|---:|---|
| iid_pick | pick | 20261011 | 180 | 六物体独立均匀随机 |
| iid_place | place | 20261012 | 180 | 六物体独立均匀随机 |
| balanced_pick | pick | 20261101 | 120 | 每六场景随机排列六物体 |
| balanced_place | place | 20261102 | 120 | 每六场景随机排列六物体 |

目标：抓取和完整放置的场景成功率分别至少 90%。均衡组用于补充分物体覆盖。
保留全部 trial，初始化、生成、规划、执行及判定失败均计入分母；不重采样，不重置失败物体后再次计为成功。
候选姿态和放置区内候选点只在 scratch data 中预检，不算物理重复尝试。

维持 v1.0.0 的六物体、原生尺寸和质量、x/y/yaw 范围、目标区域和成功判定阈值。
明确的环境修正：pudding_box 改为稳定端面直立；接触采用 elliptic、impratio=10、condim=6，
含已配置的滚动摩擦；夹爪刚度 1000 N/m，力上限 40 N；机械臂偏置力补偿。
因此前后对比代表整体系统改进，不能将全部增益归因于抓取算法，也不代表真实机械臂已标定性能。

每组 summary 保存代码源文件 SHA-256、资产版本、依赖版本、物理参数、抽样策略与种子。
同轮所有正式组的源文件 SHA-256 应一致。报告点估计及 95% Wilson 区间，不将样本结果解释为普遍保证。
