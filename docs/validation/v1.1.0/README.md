## 复现与范围

运行 `python scripts/benchmark_reliability.py` 复现四组，结果保存到新的 outputs/reliability_* 目录。
运行 `python scripts/check_reliability_evidence.py` 审计已记录数据与当前源文件的一致性、力上限和成功阈值。
物体尺寸、质量和 x/y/yaw 范围保持不变；物理求解/控制和稳定初始化修正见 protocol.md 与性能报告。
仍为六种已知物体、单物体、oracle pose 仿真。计时包括本机并行任务影响，不作为严格速度基准。
公开 summary 的输出位置按项目相对路径记录，其他参数保留原值。
