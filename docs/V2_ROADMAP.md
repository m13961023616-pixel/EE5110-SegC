# v2.0 验收与分阶段开发

最终场景：一个透明外观目标，至少三个同时活动的刚体干扰项，以及挡板/立柱等多组件固定障碍；实际抓取、越障搬运、释放与稳定放置。

按以下顺序实现，完成可验证阶段后提交/推送，最终通过 PR 合并与发布：

1. 主动感知：有界逐批采集、几何覆盖/估计稳定性判断、提前停止和观测不足拒绝。
2. 接触反馈/恢复：夹持监测、受限预载调整、安全退回、有限次数重新观测/换候选；一次场景只初始化一次。
3. 联合挑战：估计抓取姿态与复杂障碍规划；明确场景地图和接触观测使用的模拟假设。
4. clutter：干扰物保持碰撞与重力，保留遮挡；目标操作之外记录邻物扰动和意外接触。

正式评估使用冻结源码、新种子、各目标均衡样本、配对对照。报告首次成功率与恢复后成功率、采集帧数、规划开销、失败阶段、邻物最大位移与碰撞。

透明感知延续 v1.4 的明确合成光学模型，并扩展固定缺失/多物体遮挡；不将 alpha 渲染称为折射模型。目标选择的语义信息来源必须记录，不得在估计器中回退到真值位姿。

保持原 80 mm/1 s 抬升、95%双指接触、55 mm放置、0.02 m/s稳定速度及40 N力上限。邻物扰动作为独立成功条件，阈值在正式实验前冻结。
